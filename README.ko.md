# Token Monitor AIoTech

[English](README.md) · **한국어**

[Javis603/token-monitor](https://github.com/Javis603/token-monitor)를 기반으로 AI 도구 사용량, 추정 비용, 제공자 한도를 확인하는 Mac 메뉴바 앱입니다.

**현재 상태: 로컬 개발·검증 중. 공개 설치본은 아직 없습니다.** 이 저장소는 배포 안내와 진행 기록용이며, 개발 소스나 앱 다운로드를 제공하는 상태가 아닙니다.

## 사용 흐름

메뉴바 아이콘에서 간단한 사용량 요약을 열고, 상세 화면이나 사용 대시보드로 들어갔다가 요약으로 돌아옵니다. 도구·모델 비교, 추이, 검색·정렬, 창 크기 조절, 통화 표시 선택을 다듬어 왔습니다. 소스 테스트와 합성 화면 검증이 모든 제공자 연결이나 실제 앱의 모든 흐름을 보증하지는 않습니다.

## 숫자를 읽는 기준

- 제공자 한도와 로컬에서 관측한 토큰 사용량은 다른 지표입니다.
- 에이전트·도구별 보기와 모델별 보기는 같은 관측을 다른 기준으로 보여줄 수 있습니다. 두 보기를 별도 사용량처럼 더하지 않습니다.
- 제공자·에이전트 기록을 하나의 총합으로 제시하기 전에 귀속과 중복 제거를 검증해야 합니다.
- 누락·오래된 값·부분 수집·사용 불가는 사용량 0이 아닙니다. 최소 잔여율에는 해당 제공자와 기간이 함께 있어야 합니다.
- 추정 비용은 청구서가 아닙니다. 통화·환율 기준·기간·집계 범위를 확인해야 합니다.
- 계산을 최적화하더라도 수집·한도 경고 주기는 유지합니다. 합성 CPU 시간 감소만으로 실제 앱의 전력 절감을 주장하지 않습니다.

## 제품 방향

개인 Mac 앱, 독립적인 소규모 팀 서버, 선택적 AIoTech 전용 연결을 분리하는 구조입니다. 프롬프트·응답·인증값·원본 경로를 개인 기기에 유지하는 것이 개인정보 보호 기준입니다. 이는 설계 경계이며 팀 서버·연결 기능 전체의 검증 완료를 뜻하지 않습니다. 감시·집계에는 LLM을 호출하지 않는 방향입니다.

## 다운로드와 개발 소스

현재 사용할 수 있는 공개 설치 명령은 없습니다. 향후 서명·공증된 Mac 앱 다운로드와 동일한 검증 버전을 설치하는 Homebrew Cask를 제공합니다. GitHub 소스 압축 파일을 앱 설치본으로 해석하면 안 됩니다.

개발 소스 백업은 이 공개 저장소와 분리합니다. 비공개 저장소를 사용하더라도 향후 Electron 앱에 포함된 코드를 추출할 수 없다는 보장은 아닙니다. 원본 고지는 보존하며, 최종 제품의 배포 조건은 검토 중입니다.
